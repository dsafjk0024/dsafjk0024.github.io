Overview

This project studies world-model-based reinforcement learning for legged locomotion, end-to-end from simulation to a physical robot. I rebuilt the training stack into a custom RL framework so that world-model variants could be compared under identical, reproducible conditions — then deployed the learned policy on real hardware.

What I did

  • Refactored an existing codebase (SimDist) into a modular RL framework built for controlled ablations.
  • Trained a locomotion policy and deployed it on a physical Unitree Go2 quadruped at 50 Hz.
  • Built the full proprioceptive observation pipeline (joint position/velocity, projected gravity) over the Unitree SDK.
  • Ran a comparative evaluation of a vanilla world-model baseline against a dynamics-tuned variant.
