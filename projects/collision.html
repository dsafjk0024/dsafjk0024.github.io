Overview

A reactive collision-avoidance system that lets a manipulator slow down near obstacles using only perception — no dedicated proximity sensors. Getting it to work on real hardware relied on closing the sim-to-real gap first.

What I did

  • Achieved sim-to-real transfer via system identification in MuJoCo, cutting trajectory-tracking error by 45%.
  • Designed a Dynamic Velocity Damping architecture that scales motion by obstacle distance.
  • Computed obstacle distance from point-cloud data using the GJK algorithm.
  • Validated the full system at 30 Hz on a real xArm6 without any proximity sensors.

Stack

MuJoCo · system identification · point cloud · GJK · xArm6
