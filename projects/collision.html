GJK Distance-Based Velocity Damping for Collision Avoidance

GJKminimum distance, capsule ↔ convex hull

Overview

A distance-based control layer slows the xArm6 as obstacles approach. A RealSense D435i depth camera supplies obstacle point clouds. Robot links are approximated by capsules and each obstacle point cloud by its convex hull; GJK returns the minimum distance between the two convex shapes. Within a configured threshold, that distance scales the motion velocity without replanning the path.

The setup uses a depth camera, with no dedicated proximity sensors on the robot. It does not infer obstacle locations without sensing.

Design decisions

  • Convex geometric approximation. Capsules for the links and a convex hull per obstacle point cloud keep both operands convex, which is what GJK requires; the query returns a signed clearance the controller can act on directly.
  • Distance-based damping. Motion slows as clearance decreases inside the threshold, allowing the controller to react each cycle without a new path-planning solution.
  • Simulation-to-real validation. MuJoCo-based system identification supported transfer to the xArm6, where the controller was exercised at 30 Hz.

Results

Qualitative. The arm slows as the obstacle closes and stops short of contact, in simulation and on hardware, for obstacles introduced by hand during motion. Clearance at stop, reaction latency and behaviour across approach speeds were not measured — the videos are the evidence as it stands.
