Overview

Nonlinear hand dynamics, friction and modeling errors leave residual torques that degrade joint tracking. Changing wrist orientation changes the gravity direction relative to the hand. I added a Radial Basis Function Neural Network (RBFNN) compensation layer to the Allegro Hand’s existing PD controller to estimate and compensate these torques online.

The work has two stages: tracking multi-frequency trajectories without a grasped object across wrist orientations, and adapting the same control structure to hold a grasped object under disturbances.

Online adaptive compensation

The network takes joint position and velocity, tracking error and its time derivative, and a normalized gravity vector expressed relative to the hand. Gaussian basis functions map these inputs to a residual torque estimate; an adaptation law derived from Lyapunov analysis updates the weights at each control step.

The RBFNN torque is added to the existing PD torque command. The gravity input makes wrist orientation explicit. Tracking tests and grasp-holding tests use the same control structure but represent separate evaluations.

Tracking results

The comparison uses Allegro Hand joint 7 with the same multi-frequency reference trajectory under the built-in PD controller and PD plus RBFNN compensation. Tests were repeated across wrist orientations. The plotted error ranges are approximately −0.6 to 0.6 rad for PD and −0.15 to 0.15 rad with compensation.

Grasp holding and research outputs

No object drop was observed in the compensated grasp-holding trials shown. Trial counts were not recorded, so this is qualitative evidence rather than a success-rate estimate.

The tracking-control work was presented as Adaptive Control of a Multi-Fingered Dexterous Hand via RBFNN-based Residual Torque Compensation in 2025. The grasp-holding work was presented as RBFNN-Based Online Disturbance Compensation for Robust Grasping at KRoC 2026. Both are first-author posters; the two evaluations are reported separately.
