74% vs 60%을 "이겼다"로 말하지 않는다. 통계 근거(프로젝트 페이지): 범위 내 50 + 범위 밖 10 = 60회 전체를 대응표본으로 비교했고, 한쪽만 성공한 22회가 14:8. 동전 던지기와 구분 안 되는 수준(McNemar p = 0.29). 위치별 실패 쏠림은 Fisher p = 0.001. 물어보면 그때 꺼낸다. flow matching의 ODE 샘플러가 replan당 ~100 ms라 27 Hz. "왜 끝냈나" 질문 오면: 실제 로봇 시연 수집의 커버리지 한계가 실패 분포로 드러났고, 후속 단계의 시뮬레이션 데이터 생성 · co-training · 실제 로봇 deploy 성과는 이어지는 슬라이드에서 제시. 실패 비교 영상: 왼쪽 OOD run52(0–8.233초), 오른쪽 적층 실패 run04(0–9.133초). 짧은 왼쪽은 마지막 프레임 유지. 원본 속도 유지. 사례의 알고리즘 소속은 확정하지 않음.

Flow Matching 입력 자체의 촉각 확장이 아니라 Residual policy의 observation 확장. 후속 논문: Tactile-Guided Residual Reinforcement Learning for Precise Connector Insertion. RoboWorld 2024 의 53% 를 이 policy 결과로 재사용하지 않는다. 필요한 결과 · 자료 목록: docs/project03-rl-evidence.md. 통합 전 학습 구조 설명: 추가 입력은 접촉력·질량이 아니라 참값 기반 상대 위치 6-D. dynamics randomization 미사용. 목적과 구현을 설명하는 장이며 성공률 향상을 확정하지 않는다. cfg 기본값 CRITIC_PRIVILEGED=false 가 대조군. 개선 수치 인용 전 원본 로그 · checkpoint · 학습 seed 수를 확인한다. 삭제한 본문 부연설명: 두 영상은 같은 태스크의 예시 rollout 이다 — 반복 성공률 · 도달 오차 · 완료 시간은 미집계. 본문 용어 설명: policy=Actor, 학습 평가망=Critic. Actor 관측31-D. Critic 추가6-D는 참값 기반 상대 위치이며 실제 로봇 policy에는 들어가지 않는다. 물체 위치 bias ±15mm는 에피소드 단위 고정.팀 공동 기반 위의 통합 · 학습 · deploy. GASP를 새로 제안했다는 주장이 아니다. 학습 대상은 오른팔·오른손이며 양팔 동시 RL이 아니다. 상대 위치 9 = grasp–object / grasp–target / object–target 각 3. 행동 22차원은 관절 22개가 아니다. 근거: gasp/train_relocate.py, env/relocate_env.py. 삭제한 본문 부연설명: xArm7 + Allegro Hand · 관측 31-D → 행동 22-D · 시연 수집에서 강화학습 연계 영상 편집: Symmetric 실패 영상 0–9.2초(손이 다시 올라오는 지점까지), 이어 Asymmetric 성공 예시 12.8초 전체. 원본 속도 유지. 왼쪽 상단 각 policy 이름 표기.
